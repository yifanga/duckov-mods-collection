# Duckov Mods Collection

This repository is a monorepo that aggregates several Duckov mods while preserving their individual histories.

## Included mods
- AutoPickKeyAndRecipe
- DuckovBetterRealDog
- KeyUsedTime
- LootNearbyItem
- TagInventoryWeight

Each mod keeps its own README inside its folder. Original author notes and external links are preserved there.
