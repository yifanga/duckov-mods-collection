[h1]一键搜索散落物 [/h1]

[h2]理包时想要的地面物品找不到怎么办？[/h2]

不要急！订阅本MOD后，按下 [b]H键[/b] 即可像搜索箱子一样搜索地面物品，快速定位目标物品！
(注意，本mod纯粹为辅助mod，不是全图搜索，物品的一键拾取范围和人物默认拾取范围一致)

除了[b]一键搜索附近地面散落的物品[/b]外，目前还支持：
➤ 搜索附近的战利品箱子（只搜索敌人死亡后生成的箱子，并且会跳过搜索过程），本功能需要参考更新说明从配置中开启，默认是关闭的
➤ 支持调整战利品箱子搜索半径（默认10m），地面散落物搜索半径保持0.3m不变。
➤ 支持搜索附近战利品箱子时自动卸载子弹，优先搜索最近箱子。

配置文件修改方法：
每次勾选启用mod会尝试读取配置文件，不存在时会生成默认配置文件，配置文件目录位于mod管理页面顶部的mod目录文件夹内。
打开mod目录中的LootNearbyItem文件夹，其中config.txt即为配置文件。
1.建议先删除config.txt, 然后再各停用和启用一次mod以获取最新支持配置字段（无需重启游戏）。
2.之后再根据config.txt中的说明修改配置并保存。
3.最后再各停用和启用一次mod，使最新的配置生效（无需重启游戏）之后就可以进入存档了
