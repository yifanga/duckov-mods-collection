[h1]One-Key Ground Item Search [/h1]
[h2]Can't find items on the ground while organizing?[/h2]
Don't worry! After subscribing to this MOD, press the [b]H key[/b] to search ground items just like containers, quickly locating your target items!
(Note: This is a pure assistance MOD, not a full-map search. The one-key pickup range matches the character's default pickup range)
