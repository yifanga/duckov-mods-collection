[h1]一键搜索散落物 [/h1]

推荐三种使用模式∶

⭐默认配置∶安装即用，避免物品重叠捡不到的高血压场景

⭐进阶配置∶开启敌人战利品搜索，打完敌人原地一键舔完所有包，用过之后直接忘掉F键

⭐开挂模式∶所有选项开启和拉满，一键扫荡，进图如秋风扫落叶，走过的地方寸草不留

[h2]理包时想要的地面物品找不到怎么办？[/h2]

不要急！订阅本MOD后，按下 [b]H键[/b] 即可像搜索箱子一样搜索地面物品，快速定位目标物品！
(注意，本mod不是全图搜索，一键搜索范围默认和人物拾取范围一致，可自定义调整)

除了[b]一键搜索附近地面散落的物品[/b]外，目前还支持：

➤ 支持[b]一键搜索附近敌人掉落的战利品箱子[/b]（需配置开启，默认关闭）
➤ 支持[b]一键搜索附近的各种容器[/b]（指非敌人掉落的容器，需配置开启，默认关闭）
➤ 一键搜索时自动卸载子弹，自动物品堆叠合并和排序，优先搜索最近箱子

除了功能单独开关，也支持分别自定义配置，包括：
➤ 支持保留搜索过程（默认关闭）
➤ 支持自动拆出武器等插槽内的物品（开启后全局生效，默认关闭）
➤ 支持单独调整敌人战利品箱子搜索半径（默认10m）
➤ 支持单独调整非敌人战利品箱子的容器搜索半径（默认0.3m，官方设定值）
➤ 支持单独调整地面散落物搜索半径（默认0.3m，官方设定值，不建议调整）
➤ 增加了实验性功能开关：是否在脚下生成临时垃圾堆盒子(谨慎开启!!!启用后右侧剩余物大于15时触发，理论上可降低非常极端情况的负载)

[h2]Can't find items while organizing?[/h2]
Press [b]H[/b] to instantly locate nearby ground items! 
(Note: Not full-map scanning - range matches vanilla pickup distance)
Also supports:
➤ Search nearby [b]enemy loot containers[/b] (configurable, default off)
➤ Search nearby [b]non-enemy containers[/b] (configurable, default off)
➤ Auto-unload ammo, item stacking/sorting, priority nearest container
Customizable features:
➤ Keep looting animation (default off)
➤ Auto-unplug items from slots (e.g. weapons) (global, default off)
➤ Adjust enemy loot radius (default: 10m)
➤ Adjust non-enemy container radius (default: 0.3m)
➤ Adjust ground item radius (default: 0.3m - not recommended)
➤ Experimental: Spawn temporary container at feet when >15 items remain (Use with extreme caution!!!)
