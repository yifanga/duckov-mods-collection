[h1]一键搜索散落物 [/h1]

[h2]理包时想要的地面物品找不到怎么办？[/h2]

不要急！订阅本MOD后，按下 [b]H键[/b] 即可像搜索箱子一样搜索地面物品，快速定位目标物品！
(注意，本mod纯粹为辅助mod，不是全图搜索，物品的一键拾取范围和人物默认拾取范围一致)

除了[b]一键搜索附近地面散落的物品[/b]外，目前还支持：

➤ 支持[b]一键搜索附近敌人掉落的战利品箱子[/b]（需要从配置中开启，默认关闭）
➤ 支持[b]一键搜索附近的各种容器[/b]（指非敌人掉落的容器，需要从配置中开启，默认关闭）
➤ 一键搜索时自动卸载子弹，自动物品堆叠合并和排序，优先搜索最近箱子

除了功能单独开关，也支持分别自定义配置，包括：
➤ 支持自动拆出插槽内物品（针对武器等带插槽物品）（开启后全局生效，需要在配置中开启，默认关闭）
➤ 支持单独调整敌人战利品箱子搜索半径（默认10m）
➤ 支持单独调整非敌人战利品箱子的容器搜索半径（默认0.3m，官方设定值）
➤ 支持单独调整地面散落物搜索半径（默认0.3m，官方设定值，不建议调整）
➤ 增加了实验性功能开关：是否在脚下生成临时垃圾堆盒子(谨慎开启!!!启用后右侧剩余物大于15个触发，会在脚下生成一个临时战利品盒子)

[h1]One-Click Ground Item Search[/h1]
[h2]Can't find items while organizing?[/h2]
Press [b]H[/b] to instantly locate nearby ground items! 
(This is an assist mod - pickup range matches vanilla settings, not full-map scanning)
Also supports:
➤ Search nearby [b]enemy loot containers[/b] (configurable, default off)
➤ Search nearby [b]non-enemy containers[/b] (configurable, default off)
➤ Auto-unload ammo, item stacking/sorting, and priority search for nearest container
Customizable features:
➤ Auto-unplug items from slots (e.g. weapons) (configurable, default off)
➤ Adjustable enemy loot radius (default: 10m)
➤ Adjustable non-enemy container radius (default: 0.3m)
➤ Adjustable ground item radius (default: 0.3m - not recommended)
➤ Added experimental feature toggle: Spawn temporary loot container at your feet when remaining items > 15 (Use with extreme caution!!!)
